# Reusable and Automated Sandbox Environment

## Instructions

### Course Sandbox

## Lab Goal

Set up a reusable and automated sandbox environment to store student code and projects for the duration of the Rust data engineering course.

## Lab Description

In this lab, you will create a central Git repository to serve as a sandbox for code created in the Rust data engineering course. You will structure the repository, set up automation, and prepare documentation to support collaboration and code sharing during the course.

## Lab Steps

- Create a new repository on GitLab or GitHub to hold the course code.
- Add a README providing an overview of the repository structure and purpose.
- Create subfolders for each week/module of the course.
- Add a Makefile to each subfolder with format, lint, test, and build commands.
- Set up GitLab CI/CD or GitHub Actions workflows to run on push.
- Write documentation for projects using Markdown.
- Create labels and milestones for tracking issues and progress.
- Add a Contributing Guide for open source contributions.
- Set up remote environments with Codespaces or CodeCatalyst.
- Create a Pages site for demos, reports, and documentation.
- Explore the code in this interactive repo.

## Reflection Questions

1. How can setting up extensive automation from the start improve team collaboration?
2. What are some key differences when structuring a class sandbox versus a real-world project repository?
3. How will documentation and artifacts on the Pages site facilitate learning?
4. What are some specific ways to encourage contributions in a class environment?
5. How can having remote reproducible environments help students troubleshoot issues?

## Challenge Questions

- Explore adding custom GitHub Actions or GitLab CI workflows beyond the basics.
- Set up auto-deployment of the Pages site on push using Actions or a pipeline.
- Research integrating badges to display project status and quality.
- Consider easy ways to cross-link code and documentation.
- Brainstorm ideas for using Issues or Merge Requests during group projects.
